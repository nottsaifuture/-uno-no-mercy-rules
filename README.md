# UNO Show 'Em No Mercy Helper

A kid-friendly, single-page rules helper for **UNO Show 'Em No Mercy**. It needs no install and works offline: just open `index.html`.

**Play it:** https://nottsaifuture.github.io/-uno-no-mercy-rules/

## What's inside
- 🏠 **Start**: how to play in 7 steps, plus a "What should I do?" picker
- 🃏 **Cards**: tap any card to see what it does, with a tip
- 🏗️ **Stacking**: build a draw-card tower (same or higher only!)
- 😱 **Mercy**: watch the meter. 25 cards and you're out
- ⭐ **Score**: points calculator, first to 1,000 wins
- 🧠 **Quiz**: 10 random questions with a saved best score

Families play differently, so check the rule sheet in your box for house rules.
